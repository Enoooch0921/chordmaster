# 第 0 小節：弱起拍

第 0 小節是正式第 1 小節前的不完全小節，不計入段落小節數。直接在預覽開頭點「＋ 弱起」，或點既有弱起的音符，即可開啟預覽快捷鍵盤，不需要左側編輯模式。可切換簡譜與節奏、調整長度、移除弱起，並沿用草稿的復原、重做、取消與完成。左側編輯器仍保留「新增弱起拍（第 0 小節）」入口，預設一拍；長度選單以四分音符為一拍，提供四分之一、半拍、一拍、一拍半等短於全曲小節的選項。6/8 中三個八分音符顯示為 1.5 拍，選單旁會明示計算單位。

只需輸入弱起的簡譜或節奏，不必加入起奏前的休止符來補成整小節。預覽把弱起放在段落名稱下方的既有左側留白，不增加欄位；每行四小節的寬度與小節線仍完整對齊，只顯示音符，不額外標示弱起名稱或拍數；保留多聲部、音值及後續正式編號。該欄也用於演出與 PDF 譜面。

`pickup.timeSignature` 僅表示弱起的容量與拍格分組，例如 `1/8` 是半拍、`1/4` 是一拍、`3/8` 是一拍半，不會改變 `song.timeSignature` 或後續小節的拍號。新的弱起內容採明確音值，不因拍格分組變更而把四分音符縮成八分音符。

未設定此欄位的舊歌曲，顯示時只收起所有聲部共用的起奏前空拍格與未使用尾格，不變更儲存資料；真正休止符仍完整保留。開啟預覽編輯時，會先在可取消的草稿中轉換成對應長度；左側編輯器則在選擇長度時重新分組。任何聲部超出新長度都會阻止縮短。貼入超長內容時會提示，避免靜默截斷。輸入游標以音符下方的小箭頭顯示；填滿後停在弱起末端，再輸入會提示調整長度，不會自動選取並覆寫上一音。刪除會移除選取音符，或移除插入游標前的一音。

弱起目前支援主簡譜、其他簡譜聲部與節奏。此功能不自動推算末小節的互補長度，也不修改歌曲庫中的既有曲譜。

預覽鍵盤內部以單一虛擬小節重用既有音符指令，寫回時只取弱起的簡譜、其他聲部與節奏欄位。虛擬段落不會寫入歌曲；草稿、復原與儲存皆保存完整原歌曲。
