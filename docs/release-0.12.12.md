# 0.12.12 — 個人筆記與積木曲序

- 曲序可設定歌曲庫預設及每場歌單的個別版本，並顯示於各頁頁首；歌曲設定上方提供顯示開關，關閉時恢復原本標頭排版。
- 採用已選定的「積木拖排」編輯器：點選段落快速加入、拖動排序、調整遍數、複製、刪除及復原。保留自訂名稱、前後插入及恢復預設。手指直接滑動捲頁，按住約 350 ms 後才拖動，避免長曲序被誤排序。
- 加入登入帳號專屬的手寫筆記，支援一般、歌單與演出譜面；筆跡與共享樂譜分開儲存。提供畫筆、透明混色螢光筆、擦除及復原，畫完停筆可修整常見圖形。改善即時筆跡回饋，抑制手寫時的文字選取與長按選單。
- 段落最後一小節預設使用雙小節線，保留反覆、終止及使用者手動指定的一般小節線。
- 修正手機上箭頭與演奏標記重疊，以及跨小節連結線被裁切；完整顯示 Pc2 等曲序代碼。
