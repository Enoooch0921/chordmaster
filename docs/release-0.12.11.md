# 0.12.11 — 手機斜線輸入修正

同一個 `/` 鍵依目前那一拍的內容判斷：空拍輸入延長拍斜線；已有和弦根音時進入低音輸入，例如 C/E。低音輸入中再次按 `/` 可退出，原有升降記號操作保留。已是延長拍時再次按鍵仍保留斜線，不會產生預設 C 和弦。

鍵盤配置不變，不增加按鈕或選單，適用手機、平板及桌面功能鍵，也支援級數和弦。

## 驗證

165 項鍵盤測試通過，包含新增的空拍、重複點按、延長拍改回和弦、級數低音及手機低音升降記號案例。WebKit 在 390×844 畫面完成輸入 C/E 及獨立延長拍，重新載入後內容保持正確。沒有實體手機測試。
