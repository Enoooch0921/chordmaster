# 介面排版檢查與修復（2026-09-12）

延續團隊管理視窗的修改，本輪檢查 App 內的側欄展開區、分享流程、手機選單、通知及名單類對話框，修復六處相似的排版問題。

| 介面 | 原本問題 | 完成的修改 |
| --- | --- | --- |
| 分享連結／聯絡人 | 連結、聯絡人名單和數個操作堆在同一視窗；複製按鈕排在最下方 | 分成連結與聯絡人兩個頁籤；複製與系統分享緊鄰連結；聯絡人可搜尋且送出按鈕固定於名單外 |
| 手機「更多」 | 譜面、語言、帳號及分享混排，分享必須往下找 | 分為譜面操作與帳號設定；分享移到譜面操作；選單依內容高度呈現且限制於視窗內 |
| 通知 | 下拉面板依附鈴鐺容器，可能被側欄裁切或越出窄螢幕；長名稱截斷 | 使用 portal 與既有定位 hook，依可用空間定位；標題區固定，名單獨立捲動；名稱換行、增加關閉與 Escape 支援 |
| 個人歌曲匯入團隊 | 手機保留桌面外框留白，標頭／搜尋／操作區可能受到長名單擠壓 | 手機使用完整視窗，桌面限制高度；步驟提示、搜尋與底部操作保留空間，名單獨立捲動 |
| 歌單協作者指派 | 長名單缺少搜尋，權限說明一直占據頂部空間 | 可搜尋姓名／信箱；顯示指派人數；說明可展開；手機全螢幕，完成按鈕固定於名單外 |
| 移動／複製歌單至專案 | 列表以 60vh 計算高度，再加標題與取消區後可能超出小螢幕 | 使用共用 ResponsiveDialog；標題與關閉固定在上方，專案列表使用剩餘空間 |

另外，聯絡人分享現在會等待操作成功才清空選取，失敗會在視窗內顯示錯誤並保留選取，避免原本 callback 沒有回傳 Promise 而過早清空的情況。

## 檔案

- `src/components/ResponsiveDialog.tsx`：手機／桌面對話框共用外框。
- `src/components/ShareDialog.tsx`、`ShareContactPicker.tsx`：連結與聯絡人分享流程。
- `src/components/NotificationBell.tsx`：通知定位與長列表。
- `src/components/TeamSongImportDialog.tsx`、`SetlistAssignmentDialog.tsx`：名單空間與固定操作區。
- `src/App.tsx`：整合分享與專案視窗、手機更多選單分類。
