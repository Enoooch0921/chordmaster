# 樂句弧與同音連線

簡譜使用 `[...]` 保存外層樂句弧，既有 `( ... )` 保存同音線，兩者可以重疊並獨立顯示。例如 `[5_ (3_ 3_) 1]` 的樂句弧連5到1，同音線只連兩個3。

跨格例：第一格末 `[(5_`，下一格 `5_) 4_ | 4_ (3_ | 3_) 1.] |`。短線連前後兩個5，外弧則一直到最後1，不會提早停在下一格首5。

方括號不增加音頭或拍數。重複方括號可表示多層樂句弧；轉固定音名、移調、JSON與剪貼簿保存端點。整張譜依各聲部獨立累計跨格弧線，在同一行接到下一格正確目的音头，換行則保留兩側半弧。編輯音高不改弧線；刪除端點或改成休止會清除該弧兩端，避免錯接後續音符。

只依原譜加入樂句弧，不用弧線推算延長時值或加入未知音符。
