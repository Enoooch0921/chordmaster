# 0.11.18 — 鍵盤、和弦間距與節奏排版

2026-10-30。

三種輸入鍵盤採一致的按鍵、字型與顏色選單。手機與平板按住根音、和弦性質、修飾詞、音符或簡譜鍵時會放大預覽，放開後輸入。桌面和弦鍵盤預設只顯示功能鍵，收合後仍保留顏色列；小節操作使用三點選單，整小節輸入另以文字明示。

手機橫式調整為緊湊的兩列按鍵配置，和弦可切換輸入／功能頁，聲部與速度移到設定彈層。按鍵區不捲動，進階三連音時值在節奏鍵盤內展開；容量不足提示浮在鍵盤上方，不改變其高度。正式元件包含整理稿的樣式，並支援深色主題。

和弦性質改為替換，重按 sus／add／alt 不再累加未完成片段；Slash Bass 選根音後仍可輸入低音升降記號。修正節奏從尾端空白退格後，新音符覆寫前一音符的問題。

密集四和弦小節保留更多留白，必要時統一壓窄寬度，維持字高、原等寬小節與四拍錨點。〈一道江河（2022 新版）〉G 調主歌第 14 小節的四個和弦以 85% 寬度顯示，實際間距約 10px。

節奏連桿依 Bach 字形外框對齊符桿，混入叉頭時維持普通音符字形；重音改為楔形，連接線採兩端漸細的弧線。三連音使用細括線及襯線斜體數字，依可見墨跡置中；短括線同步調整缺口、字級與短鉤。連桿超出三連音範圍時保留括線，完整三連音連桿僅標數字。停用連桿仍依設定顯示獨立符尾。

此版本只有前端與輸入行為修正，沒有修改正式歌曲、曲庫、歌單資料，也不執行資料庫 migration。

測試與發布結果記錄於本機 `output/release-0.11.18/verification.json`；詳盡的分階段證據見鍵盤、節奏及四和弦排版檢查文件。

## 驗證

完整回歸通過 169 檔、1869 項；型別檢查與正式建置通過。正式元件樣式下，Chrome 與 iPad Pro 11 M5／iPadOS 27.2 RC Safari 模擬器各驗證 36 組淺／深色版面，涵蓋手機橫直式、較矮的手機橫式、平板與桌面，沒有按鍵區捲動或裁切。另驗證修飾詞、低音升降記號、節奏／簡譜輸入、刪除與復原、顏色、按住預覽及提示高度。

以正式建置版的本地模式新增測試歌曲，和弦、節奏與簡譜輸入後儲存並重新載入，內容保留；手機尺寸按住預覽不改變鍵盤高度。三連音另有各 288 組 Chrome／iPad Safari 量測，以及數字墨跡的截圖像素核對。未將實機 iPad Chrome 或藍牙翻頁器列為本次驗證項目。
