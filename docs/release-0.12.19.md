# ChordMaster 0.12.19 — 2026-11-07

全螢幕歌單會在瀏覽器空檔先排好上一首和下一首的譜。點按或滑動換歌時，可以直接顯示已排好的曲目。左右翻頁箭頭與邊緣淡光已移除，仍可點按、滑動或使用踏板翻頁。

## 在 iPad 試用

1. 在 Safari 或主畫面上的 ChordMaster 開啟工作區。若已進入演出模式，先退出演出，看到更新提示後點「立即更新」。
2. 確認開啟時顯示 **v0.12.19**，進入平常使用的歌單與演出模式。
3. 到第一首的最後一頁，點右半邊換到下一首，再向右滑回上一首的最後一頁。

本機 WebKit 以合成歌單各測 8 次跨歌，從輸入到第二個畫面更新回呼的中位數由 189 毫秒降至 91 毫秒。實體 iPad 的反應時間仍待量測。
