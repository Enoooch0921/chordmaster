# ChordMaster 0.12.31 — 2026-11-08

## 歌詞雙指縮放

在歌詞上張開兩指可放大，捏合可縮小。一般閱讀、專注閱讀、全螢幕演出及分享頁都可使用。移動手指時會即時預覽，放開後依新字級重新分欄、分頁。閱讀設定中的「本曲字級」按鈕也能調整，範圍是 20 至 40 px。

每首歌在目前裝置、目前使用者下各自記住字級。同一首歌重複出現在歌單中或切到演出畫面，都會沿用它的設定。還沒調過的歌沿用原本閱讀字級。

## 手寫與停筆修形

歌詞和樂譜的畫筆、螢光筆都會平滑細微的來回抖動。筆尖即時跟手，抬筆後保留同一條線。

開啟「停筆修形」後，一筆畫完並短暫停住，可辨識更多細長或不等邊的三角形。畫交叉五角星或沿外框畫星星時，尖角可略有偏差，起點和終點也可留小缺口。
