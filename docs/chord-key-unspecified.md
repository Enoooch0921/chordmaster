# 未標調性的原譜和弦

`Bar.chordKeyUnspecified: true` 用於原稿已寫和弦級數、但演奏目的調未標的有效小節。它只記錄本格和弦的來源調性未知，不推定全曲轉調路線，也不影響小節邊界或已確認的節奏。

保留來源級數於 `chords`、`chordSubdivisions` 與遍數和弦；勿先換成某個參考調的字母和弦。ChordSheet 在字母／數字模式、移調與capo下均顯示原記號，並標「調性未標 · 原譜級數」。它可同時具有 `chordTimingUnspecified`：調性與拍位是各自獨立的未知欄位。有來源證實的相對級數拍位仍可明確保存，例如一拍內兩次 `5`。

儲存只接受真正 boolean true。复制和弦或整格時保留來源旗標、級數與細分，不從內部參考調建立假的轉調；已知調性的其他歌曲照既有規則移調。原稿調性不明格不視作空白占位。

快捷編輯器的數字鍵與直接輸入保存原級數，未定拍位序列編輯器同樣保存原順序。選擇已確認的Key會在同一筆可復原歷史操作中設定本格調性並清除該格旗標；它不自動清除其他來源待核格。主編輯器也有逐格來源調性未定勾選欄位。只有確認原稿目的調後才取消待核，不因把工作調從G改A就推定來源調性。
