# 0.11.20 — 個人曲庫單首與批量複製到團隊

2026-10-31。

個人曲庫的歌曲「⋯」選單新增「複製到團隊…」。管理歌曲時，可勾選多首後從批量操作列送出；曲庫操作選單也提供同一入口。

視窗只列出有歌曲編輯權限的團隊，先儲存個人編輯，再檢查歌曲與確認目標。保留個人原譜，已存在的來源或同名歌曲另建獨立副本；這條新路徑沒有覆蓋選項。每次最多 500 首，不送出封存及系統測試歌曲。成功後仍停留在個人區，失敗時保留可重試的確認畫面。

離線、尚有待同步修改、工作區、登入連線或目標權限變更時停止後續傳送。既有團隊曲庫從個人區匯入的流程維持原有行為，兩個入口沿用既有 NAS RPC；沒有新增 migration。

視窗沿用共用呼出／退場、焦點與捲動管理，選取與確認之間以短暫淡入銜接。手機橫向縮短目標及搜尋區以保留列表空間，搜尋 Enter 及點選歌曲可收起輸入焦點。鍵盤操作維持即時，並支援減少動態效果。

## 驗證

功能實作通過 175 個測試檔、1,910 項測試、TypeScript 型別檢查與正式建置。手機橫直、平板及桌面共四組瀏覽器版面驗證單首與批量八條流程，另確認重複歌曲不覆蓋、鍵盤操作、減少動態效果及關閉後焦點與捲動鎖釋放。

NAS 只讀 OpenAPI 確認 `inspect_team_song_import` 與 `import_personal_songs_to_team` 已存在。本次測試沒有向正式曲庫執行複製、覆蓋或刪除，未將實機操作列為通過項目。

功能說明見 `docs/personal-to-team-song-copy.md`。本機證據在 `output/team-copy-20261031/verification.json`，發布與正式站紀錄在 `output/release-0.11.20/verification.json`；測試頁與測試資料不隨正式網站發布。
