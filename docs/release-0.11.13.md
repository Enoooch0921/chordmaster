# 0.11.13 — iPad 演出與和弦鍵盤緊急修復

2026-10-30。

- 原生全螢幕期間，翻頁器的定時、觸控與前景焦點恢復改用非輸入框；進入請求尚未完成時亦採相同保護，避免 iPad WebKit 因輸入框取得焦點而離開全螢幕。未使用原生全螢幕的獨立 App 保留原本的輸入焦點恢復。
- 手動選擇的字母／級數和弦鍵盤保存在本機偏好，關閉、進出演出模式及重載後保持。明確切換譜面顯示模式仍同步鍵盤；未指定目的調的來源級數仍維持保護。
- 空白和弦拍的刪除按鈕及 Backspace 返回上一拍，包括跨小節導航；有內容時保留逐字刪除，刪除小節仍使用小節操作。

本次僅發布前端修復，不修改正式曲庫或歌單資料。

## 驗證

新增回歸測試先重現焦點導致全螢幕中斷的機制、關閉後鍵盤重設，以及空白拍刪除按鈕停用，再驗證修復。保留既有長時間翻頁焦點、前景恢復、斷線重連、滑動防重複翻頁及全螢幕請求競態測試。

瀏覽器本機檢查與模擬測試不等同實體 iPad 驗證；原始回報影片保留於本機暫存，不納入發布。

發布前通過 163 個測試檔、1,749 項測試、TypeScript 型別檢查與正式建置。1024×1366 演出模式中確認焦點位於 DIV 且 PageDown 翻至下一頁；390×844 手機版確認字母鍵盤關閉重開維持、空白第二拍按刪除回第一拍，48 個小節均保留。本機 in-app browser 未授予原生全螢幕，WebKit 的輸入焦點退出行為以回歸測試模擬；尚未在實體 iPad 確認。
