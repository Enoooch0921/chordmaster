# 歌單與歌曲原始速度

歌單速度選單提供兩種明確操作。歌曲庫已有 BPM 時，可「還原歌曲庫速度」，只改目前這首歌的歌單副本。歌曲庫尚未設定 BPM 時，有歌曲編輯權限且可編輯目前歌單的人可按「設為歌曲原始速度」，將選定數值存回歌曲庫，供未來使用。

一般輸入、加減 BPM、「套用到歌單」與進入演出模式都不會自動設定原始速度。原曲未設定時不提供「回到未設定」按鈕，也不推測練習或演出中的 BPM 是否已被認可。使用者必須主動按下專用按鈕，介面僅保留「歌曲庫：未設定」與兩個不同範圍的明確操作，不重複顯示提示段落。尚未套用的輸入數值也會由這個明確動作先套用到歌單，再設定為原始速度。

只有目前歌曲庫的原始速度未設定時才能採用，既有原始速度不能透過此按鈕覆寫。雲端操作先儲存目前草稿，再讀取來源歌曲完整 JSON，以歌曲 ID、目前歌曲庫 ID、未封存狀態與精確 `updated_at` 保護更新。寫入內容來自新讀取的來源 JSON，只補上 BPM，不使用歌單譜面覆蓋歌曲庫；完整回傳更新後的資料。保留目前的資料列權限檢查，不新增 API、RLS 或資料庫結構。

現有其他歌單保留各自的速度與譜面。失敗時保留已調整的練習速度並要求確認來源；成功後記錄來源修改歷史，全域撤銷只還原原始速度，保留歌單的演奏速度。操作進行中暫緩自動儲存，避免與來源的受保護寫入互相干擾。

此功能隨 v0.11.5 發布。驗證包含 `TempoPicker.test.tsx`、`App.setlistSongControls.test.tsx`、`repository.originalTempo.test.ts`，以及一次性 PostgreSQL 的既有歌曲庫權限、團隊管理員與來源基準測試；測試不修改正式歌曲資料。
