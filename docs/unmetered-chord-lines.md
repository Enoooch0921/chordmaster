# 未定拍位和弦序列

原稿只將和弦放在歌詞上方、沒有小節線或時值時，以 `Bar.unmeteredChordLines?: string[][]` 保存原稿逐行和弦順序。這個 Bar 記錄是未定長度的整段，不代表一小節。不可由字距、行數、既有拍號或另一編曲猜出拍位。`[]` 仍保留此段落類型。

譜面為這種資料顯示獨立和弦序列與「拍位待核」，不顯示拍格、小節線或小節編號，也不把它算入後續小節數。原稿註記可展開查看。原稿有明確小節線的區段繼續使用既有小節資料。歌詞仍由既有 lyricsDoc 保存，不能因完整歌詞或可移調而把音樂狀態改為已校完。

預覽與舊編輯器都提供逐行文字輸入，使用譜面原調，和弦以空白分隔。預覽編輯沿用目前的草稿、復原、重做及完成流程。跨調貼上會同時移調根音與 slash bass；數字和弦、capo 與譜面調性沿用現有顯示工具。複製文字不加假小節線或拍位標籤；整段複製保留序列結構。不能用和弦貼上把既有節奏、旋律或導航轉成看不見的資料，也不能把有拍位的節奏／旋律／導航貼進未定拍位段落。

儲存正規化保留有效的逐行陣列，舊箭頭方向按既有 chordTimingVersion 遷移一次。getChordEvents 對未定拍位段落回傳空陣列，表示沒有可確認的 onset，並非休止或延續上一和弦。此欄位沒有排入播放時序的功能。

原稿沒有拍號時，以 `Song.timeSignatureUnspecified: true` 明示未知；`timeSignature` 原內部暫值保持以相容既有編輯器，不作來源證據。預覽顯示「Time - 未標」，兩個metadata編輯器提供「拍號未定」選項，未知時不顯示暫值於拍號輸入。原稿有明示拍號（例如第1547批）的歌曲不自動標未知。未定拍位段落有既有明示keyChangeTo時，預覽另列轉調提示；整首移調及數字和弦仍保留正確段落調性。

原稿沒有確認原調時，可使用 `Song.originalKeyUnspecified: true`。既有 `originalKey` 繼續作為推讀工作調供移調、數字和弦及編輯運算使用；譜面在工作調旁顯示「原調未定」，兩個metadata編輯器提供同名選項。移調或切換數字和弦不會自動確認原調；只有使用者明確取消此標記才解除。未提供旗標的既有已定原調歌曲維持原顯示，不全庫推定未知。
