# 0.11.19 — 鍵盤、手機切換與視窗動態

2026-10-31。

鍵盤呼出、收合與譜面避讓協調過渡，量測與定位維持穩定；快速開關可反向接續，手動捲動會取消自動避讓。桌面與觸控鍵盤使用各自適合的短暫過渡，不改變記譜內容。

和弦／節奏／簡譜／文字模式，以及手機歌曲／歌單、譜面操作／帳號設定切換加入滑動選取底色與短暫內容淡入；手機設定分頁維持視窗高度。

邀請、分享歌單、成員管理、協作者與其他共用視窗加入呼出與退場動畫；成員分頁及權限說明補上過渡。通知、速度設定、帳號、更多、歌單與小節操作、貼上、同步比較及草稿復原也沿用共用動態。修正即時關閉視窗時，原生對話框可能隱藏後仍占住頂層與焦點的問題。退場期間保護焦點與捲動鎖，退出的控制項立即停止互動。鍵盤操作維持即時，減少動態效果設定避免位移和縮放。

本次只發布前端。沒有執行資料庫遷移，也沒有修改正式歌曲、歌單、成員或邀請資料。

## 驗證

動畫實作通過 174 個測試檔、1,900 項測試、TypeScript 型別檢查與正式建置，建置保留既有大型 bundle 提示。手機與桌面瀏覽器測試涵蓋四種對話框、內部分頁、兩種選單、定位、關閉、鍵盤操作與減少動態效果；正式元件樣式下另有 36 組鍵盤版面量測。

iPadOS 27.2 模擬器 Safari 驗證四種視窗及鍵盤呼出、避讓、手動中斷與快速反向切換。本地完整 App 另驗證輸入後儲存及重新載入、手機導覽與小節選單。視窗測試使用測試成員及回呼，不送出真實分享或邀請；未將實機 iPad Chrome 與藍牙翻頁器列為通過項目。
