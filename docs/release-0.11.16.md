# 0.11.16 — 節奏連桿與 iPad 段落拖曳

2026-10-30。

節奏連桿改以 Bach 字型的基準線與實際符桿輪廓定位，避免 SVG 文字行框使連桿落在符桿中段。字型載入完成後重新量測，保留原音符、時值、休止符與和弦。

長按段落標籤拖曳時攔截原生單指捲動，並限制預覽邊緣的自動捲動。靜止長按不自動捲動；手指向邊緣移動後才允許緩慢捲動，放開或取消即停止。

續頁只保留頁次提示，不再重複左上角歌名。團隊歌曲轉存個人曲庫時使用原歌名，同名才附數字，並清除轉存副本繼承的團隊連結。本次不批次改名既有個人歌曲，也不修改正式曲庫或歌單資料。
