# 0.12.9 — 精簡選單與前插小節、段落

小節右鍵選單由約 542px 縮至 366px，保留 44px 點按高度。貼上種類、前後貼上及房子記號改為點開才顯示的次層；返回或 Escape 可回到第一層並還原焦點。

加入「在前面插入一小節」。段落標籤選單加入「在前面插入段落」，包含第一個段落；新增後可直接命名，取消命名仍保留新段落，可用復原移除。歌單的自訂段落順序與編輯中的復原／取消流程一併保留。

譜面註記及自訂導覽文字套用單字首字母大寫，例如 Build、To Chorus。顯示格式不改寫原始文字，既有縮寫及中文保留。
