# ChordMaster 0.12.22 — 2026-11-07

歌詞底部改成可直接點按的段落標籤，沿用曲序中的 V1、V2、C、B 等縮寫，一次點按就跳到該段所在的頁面。移除原本的上一頁／下一頁與段落下拉選單，保留左右點按、左右滑動和鍵盤／踏板翻頁。

標籤有清楚的選取狀態與短暫的底色移動；即使兩段歌詞在同一頁，點選後仍會選中對應段落。調整字級、旋轉、專注閱讀或切換列印時會保留選取的位置。鍵盤操作立即切換，減少動態效果時不滑動底色，歌詞本身保持靜止。

底部按鈕維持至少 44px，並在手機底部安全區上方再留 16px。段落較多時可橫向捲動，滑動標籤列不會誤翻歌詞頁。

## 手機和平板試用

1. 先退出演出模式，看到提示後點「立即更新」，確認版本為 **v0.12.22**。
2. 在歌詞模式打開〈點燃〉，點 V1、V2、C、B，確認一次就能跳段，選取底色也跟著改變。
3. 試著旋轉、進入專注閱讀、左右滑動翻頁，確認標籤仍可按到，且不會貼住手機底部手勢區。

Chromium／WebKit 已驗證手機和平板排版、來源行完整性、選取回饋、減少動態效果、專注／列印切換及多段落捲動。安全區另以 34px 底部 inset 的模擬版面檢查；實體裝置手感由本次試用確認。本版僅更新前端，沒有正式曲庫寫入或資料庫遷移。
