# 0.12.49 · 新歌直接在譜面編輯

2026-11-17 使用者回報正式網站按「新歌」仍開啟已要求停用的舊整頁編輯器。正式站 0.12.48 的 App chunk 仍包含 `SongEditor`、`data-editor-pane` 與舊快捷編輯偏好；移除修改當時尚留於本機工作區。

## 行為

- 新增、複製歌曲直接進入譜面，並關閉行動版導覽。
- 移除舊編輯器載入、顯示區、開啟狀態、焦點回退與拖曳分欄邏輯。
- 移除歌曲操作選單的「編輯歌曲」與快捷編輯開關。舊 `preview-quick-edit=false` 偏好不會阻止直接在譜面輸入。
- 曲庫、歌單導覽與直接編輯標題、和弦、節奏、簡譜的流程沿用現有介面。

## 設計與審查

依 frontend-design 保留既有譜面的白底、灰字與藍色選取狀態，讓新增歌曲直接落在使用者閱讀及編輯的同一份譜面。這是移除多餘頁面的流程修正，不新增視覺樣式。

依 web-design-guidelines 與 React best practices 檢查本次變更：既有新增按鈕仍使用原生 button 與可存取名稱；行動導覽關閉後顯示譜面；直接編輯保留原有焦點與草稿保護。舊元件不再進入正式建置。

## 驗證

- TypeScript、正式建置及差異格式檢查。
- 回歸涵蓋歌曲／歌單導覽切回曲庫新增、舊關閉偏好、複製歌曲及曲庫操作選單。
- 瀏覽器實測新增歌曲與點譜面輸入；正式站發佈後另行驗證版本與資產。
