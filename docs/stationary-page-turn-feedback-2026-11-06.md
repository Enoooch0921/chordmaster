# 演出翻頁改為觸點回饋

依使用者要求，取消 0.12.16 的整張譜面橫向跟手位移與回彈；減少動態效果時也不再讓譜面變透明。翻頁仍立即切換頁面，動畫集中於觸點附近。

## 行為

- 觸控時在手指上方 16px 顯示 40px 圓形方向提示，不攔截觸控、不加入螢幕閱讀器內容。
- 確認橫向滑動後，只讓這個提示跟手；達到既有 44px 翻頁門檻時提高亮度，放開直接翻頁，提示以既有 125ms 曲線淡出。
- 輕點翻頁同樣有短回饋，保留 100ms 後淡出；快速連續操作重設同一提示，不累積動畫。
- 減少動態效果時，提示固定於起始觸點。鍵盤、踏板及輔助啟用直接翻頁，不顯示觸控動畫。
- 保留短滑取消、垂直手勢排除、多指取消、手寫／控制按鈕排除與跨歌後的合成 click 防重複。觸點提示獨立於譜面及其頁面位移元素。

## 驗證

觸控 hook、演出安全性與歌詞版面共 3 檔／33 項測試通過，TypeScript 檢查和正式 build 通過。瀏覽器使用真實 App、三首合成歌曲與 Chromium CDP 觸控事件，檢查 390×844、834×1194、1440×900：滑動期間譜面的座標、大小、transform 與 opacity 保持不變；短滑不翻頁、提示可消失、跨歌與減少動態效果正常。鍵盤輸入不產生觸點動畫。

瀏覽器診斷的 Profiler 計數包含整個子樹；手機／桌面尺寸切換後觀察到其他提交，因此不以這個樣本宣稱整個 App 零重繪。hook 與演出整合測試確認手勢回饋不透過 workspace state 更新。未量測實體手機／iPad 的 FPS 或觸感。
