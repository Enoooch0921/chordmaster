# 0.12.7 — 歌單圖示比對與 iPad 演出修正

個人歌單現在也提供曲庫更新提示、實際譜面差異比對及雙向同步。未登入的本機工作區會保留同步前備份；雲端個人曲庫使用與團隊曲庫相同的版本檢查，防止覆蓋其他裝置的修改。差異以原本的小節譜面呈現，並以顏色標記變動。

歌單可選兩行或三行，預設兩行，同時保留單首歌曲明確指定的行高。歌單重新排列段落時，依原曲各小節的有效拍號補上恢復標記，避免臨時拍號影響後續段落。小節右鍵選單支援刪除與復原，編輯鍵盤也可移除已有的齊奏標記。

演出翻頁直接更新目前頁面位置與頁碼，減少整份譜面的重繪。iPad Safari 離開全螢幕後重新使用動態可視高度，退出按鈕也會離開演出模式。歌詞版面與原生鼓手 MIDI 相關的既有工作一併納入原始碼。

總管理員可將同團隊的一般成員升為總管理員；擁有者及既有總管理員的角色仍受原有保護。總管理員可查看、編輯所屬團隊全部歌單；歌曲管理員的協作範圍維持原有設定。本次發布不變更任何使用者的角色。

整合以線上 0.12.6 為基礎，保留近期鍵盤、鼓手切歌、和弦拍點與個人歌曲複製至團隊的改進。〈Upside Down〉暫不加入。

## 驗證與發布範圍

- TypeScript 檢查通過；完整 196 個測試檔案、2234 項測試通過。完整重跑採單一 worker，避免同時進行瀏覽器驗證時的資源競爭造成載入等待逾時。
- WebKit 驗證 834×1194、1194×834、390×844 的差異比對、兩／三行切換與演出退出；退出後工作區高度 834px 與視窗高度一致。
- 設計掃描的兩項主要提示均屬既有介面：停用狀態的灰色按鈕文字及關於頁既有靛色標題，未引入新色彩樣式。
- 隔離 PostgreSQL 套用 32 份 migration，5 組相關權限與個人歌單同步測試通過。
- 個人同步及總管理員授權 migration 已於 NAS 套用並備份、回讀驗證；本次發布不重新執行資料寫入。
- 網頁及 Capacitor 前端資源建置使用教會 NAS 正式端點。
- 此次發布目標為 GitHub Pages 網頁版，包含 iPad Safari；不包含 App Store／TestFlight 原生二進位發布。實體 iPad 的全螢幕切換、觸控與音訊仍需裝置回歸確認。
