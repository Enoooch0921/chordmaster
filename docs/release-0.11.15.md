# 0.11.15 — 譜面儲存提示與手機、iPad 排版

2026-10-30。

譜面右下角顯示最後成功編輯時間；尚未儲存或儲存失敗不更新。歌單獨立編曲使用該份譜的時間，沒有可靠日期的舊譜顯示「—」。切換工作區時，待儲存提示列出曲庫／歌單、歌名及修改項目，提供儲存、捨棄或取消；沒有實際內容差異或已還原的草稿不再誤報。

手機新增歌曲頁精簡導覽與狀態列，搜尋欄維持 16px、固定於可捲動清單上方，保留鍵盤上方的歌曲選取空間；按完成可收起鍵盤，中文組字期間不誤觸。手機頂部隱藏編輯模式按鈕，iPad 與桌面保留。

共用和弦排版替相鄰整拍斜線和弦保留較清楚間距；同一小節的整拍和弦使用一致的縮放比例，避免只把長和弦壓窄。保留原和弦、拍位、細分拍的排版及既有避碰限制，不依歌名特判。

主畫面與演出畫面共同校正可視高度，監聽標準及 WebKit 全螢幕切換，在過渡期間以兩種瀏覽器高度的有效範圍為界，並於動畫後有限次重測。保留雙指縮放、內部捲動及原有全螢幕焦點策略。

本次只發布前端與既有譜面 JSON 的編輯時間欄位支援，不直接修改正式曲庫、歌單資料或執行資料庫 migration。

## 驗證

完整測試通過 167 檔、1,791 項，型別檢查與正式建置通過。建置保留既有的大型 bundle 提示。

iPad Pro 11 吋 M5／iPadOS 27.2 模擬器的 Safari 原生全螢幕實測：1210px 全螢幕退出後恢復 1078px 可視高度，主畫面與演出容器底邊均回到 1078px，譜面頁尾完整可見；退出後可滑動翻頁、關閉演出模式並點選底部縮放按鈕，重新進入全螢幕亦正常。這是模擬器 Safari 的驗證，實機 Chrome 與藍牙翻頁器不在本次原生驗證範圍。
