# 簡譜重音

音符後的 `!` 表示該音的直角重音：`6_!`（八分）、`1'_!`（高音八分）、`5!`（四分）。附點放在重音前，例如 `6_.!`；連線右括號放在重音後，例如 `(6_! 6_!)`。重音不改音高、時值、拍格或起音位置，與和弦提前／延後箭頭分開。

預覽、編輯預覽與PDF共用簡譜呈現，重音置於音符／高點上方並預留高度。原譜沒有重音的音符保持既有高度。資料仍是原有 `riff` 字串，不增建另一個節奏聲部。儲存、複製貼上、固定／首調轉換及既有音符修改保留重音；改為休止或延長符時不帶重音。原有 `^` 前綴語法保持相容，未重新賦義。

此支援供有來源的器樂音符使用；原稿未知音高、時值、聲部或拍位仍須留下待核，不因支援符號就推填。
