# 小節界線已知、和弦拍位未定

原稿有小節線，但沒有可確認的和弦切點時，以 `Bar.chordTimingUnspecified: true` 保存該小節內 `chords` 的原順序。不要把兩個和弦自動解讀為第1／3拍。這仍是一個原稿小節，保留小節編號、界線、導航、節奏／器樂與其他資料；沒有小節線的整個唱段繼續使用 `unmeteredChordLines`。

`ChordSheet` 在原小節內顯示「拍位待核」及和弦順序，不建立和弦拍格或beat anchors。窄格內整行按可用寬度縮放，不把換行後的和弦擠入相鄰小節；保留註記於可點開的「註」內，印刷不展開註記。移調及數字和弦保留原調級數與slash bass音名；E調 `B/D#`、`F#/A#` 移至F#調為 `C#/E#`、`G#/B#`，數字仍是 `5/7`、`2/#4`，不先把E#、B#換成F、C再計算度數。依來源級數轉出的E#根音也保留拼法。

`getChordEvents`、`getChordBeatSlots` 和可用subdivision positions回傳空陣列，表示沒有已確認的攻擊拍位，不表示休止或延續上一和弦。拍格寫入、插入、offset操作在此模式下不改資料。原有時值欄位若存在不刪除，但不從未定和弦序列生出拍位。

完整及緊湊編輯器使用原調文字順序欄，保留小節結構與其他欄位。預覽點按或Enter／Space開啟順序編輯，可Undo／Redo；明確選「設定和弦拍位」或解除「和弦拍位未定」後才切入既有拍格編輯，其初始分配仍需使用者逐一設定。Undo可復原未定狀態。不能因本機功能存在而在NAS批次替來源確認拍位。

儲存正規化僅接受嚴格boolean true，讀寫保留旗標；移調和whole-bar複製保留旗標。chord-only貼上會帶入來源的未定旗標，已確認拍格來源則明確取代目的未定狀態；未知拍位和弦可跨目的拍號貼上，不修改目的小節拍號、節奏、器樂或導航。文字whole-bar複製仍有 `| ... |` 表達既有界線，自由唱段沒有此界線。

範例批次1553《全能奇妙神》：8個Intro原小節／10和弦的切點未署，全部保存原順序且旗標true；Verse／Chorus12和聲行／26事件以兩個自由唱段存檔。Key E及True Worshippers為原署，拍號／BPM未署。8個已知界線不是8個已知節拍或已完成校對。
