# 歌曲搜尋

歌曲庫、歌單搜尋與「加入歌曲」共用搜尋邏輯，直接在原本的搜尋框輸入即可。

| 輸入方式 | 範例 | 找到的名稱 |
| --- | --- | --- |
| 原文字、繁簡體 | 我们欢迎君王降临 | 我們歡迎君王降臨 |
| 拼音首字母 | wmhyjwjl | 我們歡迎君王降臨 |
| 拼音全拼或片段 | huanyingjunwang | 我們歡迎君王降臨 |
| 注音首字 | ㄨㄇㄏㄧㄐㄨㄐㄌ | 我們歡迎君王降臨 |
| 注音全寫 | ㄨㄛˇ ㄇㄣ˙ | 我們歡迎君王降臨 |
| 英文模式下誤打標準注音鍵位 | 5j3b4 | 主日（或名稱包含主日的歌曲） |

- 拼音不分大小寫，可輸入聲調符號，或以空格分開帶聲調數字的拼音；`lv`、`lu:`、`lü` 均支援。
- 輸入法容錯使用台灣標準大千注音鍵位，接受完整注音音節及至少三個首字鍵位。它只解讀搜尋框內容，不監控或切換輸入法。
- 文字直接命中的結果排在拼音／注音及鍵位容錯結果之前；同一類命中保留使用者選擇的排序。
- 多個搜尋詞必須全部命中，可以組合歌名首字母與作者、調性、BPM 或拍號。歌曲庫及加入歌曲均可找作者和段落名稱。
- 歌單搜尋可找歌單名、專案名或所含歌曲的名稱，並沿用當前範圍與歸檔規則。
- 保留繁簡互搜與「祢／你」容錯。數字不會任意從識別碼或和弦名稱移除，例如 `DL32`、`Em7`。
- 拼音字典在首次需要時載入，基本文字搜尋立即可用。載入中或失敗時沿用原搜尋空白狀態顯示提示。
- 讀音索引在瀏覽器內快取，歌曲更名後使用新索引；不修改儲存的歌曲名稱，也不索引完整譜面內容。

## 實作與參考

`src/lib/songSearch.ts` 統一文字正規化、拼音／注音索引、保守的鍵位解碼與結果排序。字典來自 `pinyin-pro`，以動態 import 與初始 App 分包；索引最多快取 4096 個欄位。

標準注音鍵位及解碼規則改寫自同一作者的 Spotlight Han `SearchSupplement.swift`；授權見 `docs/licenses/spotlight-han-MIT.txt`。拼音比對沿用 `PhoneticSearch.swift` 的全拼及首字母方式，讀音由瀏覽器可用的字典提供。

測試涵蓋繁簡體、完整與縮寫拼音、帶聲調與輕聲注音、錯誤輸入法、英文／數字誤判、跨欄位詞組、排序、更名、延遲載入及三個實際搜尋入口。
