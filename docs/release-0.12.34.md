# ChordMaster 0.12.34 — 2026-11-11

- 多選小節時，點到簡譜不再中斷小節選取。貼上數量不符時會列出來源與目的數量；內容相同時會提示未變更。
- 八分與十六分簡譜的選取箭頭對齊目前音符，未填滿拍子的輸入位置及密集音符的點選範圍也一併修正。
- PN 等段首標記移到弱起音符之前，弱起與後續小節的水平音符間距一致。
- 曲序編輯中，Verse 1/2 等共用段落會提供 Verse 1、Verse 2 等獨立選項，方便分別安排。
- 搜尋將完整歌名與完整縮寫排在前面，接著是歌名開頭、歌名片段、作者／版本／段名及歌詞。例如輸入 dr 時，「點燃」優先於段名或歌詞中的片段匹配。
- 和弦輸入支援 **Tab 下一拍、Shift+Tab 上一拍**。Space 仍然是下一拍，Enter 仍然是下一小節。

網頁更新後可確認畫面版本為 **v0.12.34**。若仍看到舊版，請先完成編輯，再使用「立即更新」。
