# 0.11.14 — 夜間演出紙面修復

2026-10-30。

演出模式漏了既有的紙面主題隔離標記，造成深色介面的相容樣式把譜紙由白色改成深色，但記譜仍沿用紙面墨色。現將和弦譜、歌詞與連續歌詞本共同的演出紙面容器納入既有隔離範圍，並指定淺色 color-scheme。介面與演出周圍仍保留深色。

保留 0.11.13 的全螢幕焦點、鍵盤模式記憶及空白拍刪除行為；補測沒有經過定時器的連續焦點恢復，避免只測每 1.5 秒的情況。

只修改前端主題範圍，不修改正式曲庫、歌單、排版或翻頁行為。原始回報環境經使用者更正為 iPad Chrome；本機尺寸檢查不等同實體 iPad 測試。

驗證：先以整合測試重現紙面未隔離，再通過演出、主題與焦點恢復共 11 項相關測試、型別檢查與正式建置。本機瀏覽器深色主題實測紙面由 rgb(22,27,34) 恢復 rgb(255,255,255)，文字回復深色、color-scheme 為 light；390×844 手機尺寸與桌面兩頁均確認同樣結果。原生 iPad Chrome 仍待使用者實機確認。
