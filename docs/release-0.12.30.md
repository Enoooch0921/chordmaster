# ChordMaster 0.12.30 — 2026-11-08

登入後，在歌詞模式點「手寫筆記」即可用 Apple Pencil 加註記。全螢幕演出請點「個人筆記」。支援畫筆、螢光筆、橡皮擦與復原。開著筆記時，仍可用手指點按或滑動翻頁。筆跡僅自己可見，沿用個人筆記的離線儲存與連線同步。

## 旋轉平板與調整字級

每一筆記住歌曲、歌詞段落、語言、原始行及落筆附近的字。直向、橫向或重新分欄後，閱讀器會依新排版找回那個字。手寫的形狀、距離與筆寬依目前字級等比例縮放。

橫跨數個字的水平底線或螢光標記會隨文字換行分段，轉回原方向時可以重新接合。圈圈、箭頭與其他自由筆畫會保持完整。如果圈內的詞剛好被排到兩行，一個圈只能跟著它所依附的字。直接編輯歌詞文字或刪除原段落也可能改變註記對應的位置。

歌詞筆記與和弦譜筆記各自顯示、各自復原。團隊共用的歌曲、公開分享與 A4 歌詞匯出不含這些私人註記。
