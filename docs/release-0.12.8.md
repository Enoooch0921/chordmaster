# 0.12.8 — 更清楚的譜面覆蓋方向

比對大量修改時，歌曲庫固定在左、歌單固定在右。欄名與箭頭位於捲動區之外，箭頭從「取用這份譜面」指向「這份譜面將被覆蓋」。未選方向、另存新歌曲或比對失效時，不顯示覆蓋箭頭；重新比對與版本檢查維持原流程。

固定底部說明實際覆蓋目的地，確認按鈕使用明確的取用／覆蓋文字。手機主要按鈕獨立一列；極短手機以按鈕上的完整動作取代重複的範圍說明，讓譜面保有閱讀空間。修正 WebKit 焦點捲動造成整個對話框偏移的問題。

「備份選項」可分別下載目前比對的歌曲庫或歌單版本。每個檔案只包含一首歌，以新 ID 與版本名稱匯入成個人曲庫副本；下載不觸發同步。既有自動備份、權限與並行修改保護維持不變。

## 驗證

發布前完整 196 個測試檔案、2236 項測試及型別檢查通過。實作階段的 46 項相關測試及正式建置也通過。WebKit 使用合成資料檢查 18 小節長清單、雙向切換、英文長名稱與深色模式，涵蓋 320×568、390×844、834×1194、1194×834、844×390；確認固定區不隨內容捲動且沒有橫向溢出，並實際下載及解析單曲備份。
