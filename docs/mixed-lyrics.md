# 中英混合歌詞

歌詞語言選單提供「中英混合（逐行）」：每組先顯示中文，再顯示對應英文。原有「中英對照」保留左右並排。單曲與連續歌單皆支援 A4 雙欄、大字閱讀、演出模式及 PDF 匯出。

參考：[Trust In God 歌詞 PDF 第二頁](https://drive.google.com/file/d/1VWmmyQ4SUNzdCFGzGnU-rWz2vp5hThf8/view)，來自使用者指定的[歌詞資料夾](https://drive.google.com/drive/folders/1uE9OULR0suLi9jZRFzQTYa65_DoSKxq8)。採用每欄中文／英文交替，再接續下一欄的閱讀順序。

原始換行決定逐句配對，瀏覽器自動折行不會寫回歌詞。混合版以兩種語言折行後的高度總和分頁，完整句對一起換欄／換頁。缺少翻譯不補造文字，也不增加空的翻譯列。編輯時沿用同一份中英文來源；單曲選擇保存在 `lyricsDoc.displayLanguage = "mixed"`。
