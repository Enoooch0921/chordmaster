# ChordMaster 0.12.23 — 2026-11-07

整首歌已在同一頁顯示時，底部段落標籤與頁碼會一起收起，將空間還給歌詞；需要分頁時才顯示。調字、旋轉或調整視窗後會重新判斷，仍保留手機底部安全區留白。

修正目前歌曲沒有歌詞、或所選語言沒有內容時的切歌操作。空白頁也能左右點按、左右滑動或使用鍵盤前後切歌；返回上一首仍開啟它的最後一頁。

電腦歌詞閱讀可直接使用 **←／↑ 往前、→／↓ 往後、Page Up／Page Down**，不用先點歌詞畫面。進入專注閱讀時會聚焦歌詞內容；手動操作輸入框、選單或對話框時，保留那些控制項原本的按鍵用途。演出模式繼續使用原有鍵盤／踏板處理，避免同一按鍵翻兩次。

## 試用

1. 退出演出後點「立即更新」，確認版本為 **v0.12.23**。
2. 在平板或電腦打開能整首顯示的歌曲，確認底部不再顯示段落列；縮小視窗，確認需要分頁時會恢復標籤。
3. 切到沒有歌詞的歌曲，試左右點按、滑動與方向鍵；在電腦直接按上下／左右鍵與 Page Up／Page Down，並試進出專注閱讀。

本版僅更新前端，沒有正式曲庫寫入或資料庫遷移。瀏覽器模擬檢查不等同實體手機、平板或踏板驗證。
