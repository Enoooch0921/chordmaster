# ChordMaster 0.12.24 — 2026-11-07

歌詞底部現在標示「這一頁有哪些段落」。例如同一頁顯示 Verse 1、Verse 2 與 Chorus，**V1、V2、C 會一起亮起**，底色涵蓋整組；翻到下一頁時，標示會切換至新頁實際包含的段落。跨頁續段在包含其歌詞的各頁都會亮起。

點標籤仍可直接跳到該段落的第一頁。同頁點按保留按壓回饋與段落位置記錄，整組標示保持一致。標籤較多時，橫向段落列優先完整顯示當頁標籤；整組超出寬度時先顯示第一個。鍵盤更新保持即時，減少動態設定不播放滑動，歌詞內容維持靜止。

## 試用

1. 退出演出後點「立即更新」，確認版本為 **v0.12.24**。
2. 打開需要分頁的歌詞，確認底部所有亮起的標籤都對應當頁內容。
3. 點同頁不同標籤，再左右點按、滑動或用方向鍵翻頁，確認整組標示跟著頁面切換。

整首一頁時仍隱藏底部段落列。本版僅更新前端，沒有正式曲庫寫入或資料庫遷移。瀏覽器模擬檢查不等同實體手機、平板或踏板驗證。
