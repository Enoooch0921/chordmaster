# ChordMaster 0.12.16 — 2026-11-06

整合目前主工作區與相關對話已完成、尚未發佈的修改。發佈目標為 GitHub Pages；正式資料庫及分享函式使用教會 NAS 的 self-hosted Supabase。

## 使用者體驗

- 歌曲庫搜尋重用索引與歌詞位置映射，結果顯示命中歌詞摘要，作者、版本與語言使用固定位置。
- 新增全部／最近使用／收藏與可收合的 Key、BPM、拍號篩選。登入後收藏與最近使用跨裝置同步，離線操作保留待送佇列並可重試。
- 跨搜尋共用完整已選清單，可查看、逐首移除或清空；分享、封存等批次操作使用相同範圍。
- 減少側欄與切歌時的譜面重算；修正側欄首次點按、滑出動畫、跟手拖曳、選單與選取狀態的動態回饋。
- 演出模式滑動切歌保留方向回饋，修正首次翻頁提示被個人筆記入口遮住。
- 鼓手模式 TAP／播放在按下時執行並立即變色，長按不選字，放開不重複觸發；保留鍵盤及輔助操作。
- 歌詞閱讀與列印分開，加入段落高亮、依帳號區隔的本機閱讀偏好、專注閱讀及手機底部切歌；調整平板工具排列。
- 納入指定帳號的吉他手模式入口、平板編輯鍵盤刪除效能與定位、共用複製／貼上／刪除列，以及與譜面一致的重複小節圖示。
- 調整曲序標記寬度，保留 V1&2 等多段落標籤的辨識。

已對照歌詞體驗、吉他手／鍵盤與備份／同步相關對話，以及其他工作樹的差異。舊工作樹中已被主工作區更新的版本未重複覆蓋。低光閱讀、下一首預告、段落跳轉與續讀位置仍屬後續建議，不列入本版已完成功能。

## 後端更新

先在 NAS 備份函式、權限與策略，交易內試跑後，再以單一交易套用以下 migration：

- `20261106064633_conditional_joined_workspace.sql`
- `20261106071039_library_workspace_delta.sql`
- `20261106112858_song_library_preferences.sql`

新增條件式 joined workspace、曲庫差異同步、具權限檢查的歌單項目刪除與個人歌曲偏好。五個新增 RPC 使用 security invoker，禁止匿名執行；偏好表啟用 RLS，限登入本人及目前可見歌曲。

套用前後完整既有歌曲、專案、歌單、歌單項目、成員與 Capo override 列的指紋一致。正式權限下的收藏儲存／讀回／取消與帳號偽冒阻擋驗證，在交易結尾回滾測試寫入。備份及執行證據存於儲存庫外的私人備份目錄。

分享函式保留舊用戶端回應格式，新增版本比對後的 unchanged 回應；每次仍重新檢查分享有效性及解析目前資源。只更新 `resolve-share-link/index.ts` 和 `_shared/conditionalResponse.ts`，並重啟 `supabase-edge-functions`；未更換 NAS 自訂函式路由、環境設定或其他容器。

每日本機與加密異地備份已在備份對話另行完成，不屬本次重新設定的項目。歷史 Supabase Cloud 專案未用於此次發佈。

## 驗證

- 完整 Vitest：226 個測試檔、2,540 項測試通過。
- TypeScript 型別檢查、正式網頁 build、iPad build 通過；保留既有大於 500 kB 的 chunk 提示。
- 修正批次複製回歸測試的舊按鈕名稱，使其對應目前包含已選數量的標籤。
- NAS migration 試跑與套用後完整讀回、RPC 權限及 RLS 檢查通過。
- NAS HTTP 實測：分享舊格式、新格式與 unchanged 回應一致；本次樣本回應由 5,540 bytes 降為 98 bytes。五個新增 RPC 均已載入 PostgREST，匿名呼叫回傳 401／42501。
- 先前 Chrome／WebKit 的手機、平板與桌面尺寸檢查及觸控回饋證據，見下列專項記錄。

前述瀏覽器驗證不等同於實體手機、iPad Safari／PWA 或真實雙裝置的完整回歸。這版未改動原生音訊引擎，不宣稱消除所有裝置延遲。

如前端發佈出現問題，回復至前一版前端並重新跑 GitHub Pages 部署。新增後端介面與舊版相容，可保留，避免刪除使用者新產生的收藏及最近使用。分享函式若需回復，使用本次私人備份中的原檔，僅重啟分享函式容器。
