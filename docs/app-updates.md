# 網頁版本更新

新版離線資源完整下載後，工作區會出現「有新版本可以使用」，提供「立即更新」及「稍後」。稍後會縮成可再次展開的提示；演出模式及鼓手模式隱藏提示，也不會自動重新載入。

按下更新後，先提交譜面直接編輯的草稿、等待進行中的儲存，再儲存最新工作區。儲存失敗會保留目前頁面與錯誤提示。仍在編輯器、對話框、草稿復原或切換曲庫時，需先完成該操作。

更新只重新載入按下按鈕的分頁。Service Worker 啟用新版時保留其他已開啟分頁需要的舊資源，包含離線使用的延遲載入模組；其他分頁自行決定何時更新。之後沒有開啟頁面的啟用流程才清理舊快取。

回到頁面、恢復連線及每 15 分鐘會檢查更新；隱藏或離線時略過，同一分鐘內不重複主動檢查。既有等待中的更新也會在開啟頁面時顯示。

開屏動畫於 HTML 初始畫面及 React 載入畫面都顯示 `package.json` 的版本號，由建置自動帶入。此更新提示只用於網頁版，Capacitor 原生版本沿用原生發布方式。

## 首次導入

已開啟的舊版尚未包含此提示，首次取得這項功能仍需完成一次原有的關閉分頁／重開流程。載入包含此功能的版本後，往後發布即可直接按提示更新。自 0.12.10 起提供此功能。

## 驗證

- 型別檢查、正式建置及 199 個測試檔案的 2,261 項測試通過。
- 整合測試確認歌曲庫與歌單中的直接編輯草稿先儲存再重載；儲存失敗保留修改。
- WebKit 以連續兩個建置及兩個分頁驗證：失敗重試、僅更新目前分頁、另一分頁保留未存草稿，以及離線載入舊版延遲模組後再更新。
- 檢查 320×568 窄畫面、中英語系、深淺色及 834×1194 平板畫面，按鈕高度至少 44px。開屏顯示建置版本，正式 HTML 已替換為 `v0.12.10`。
- 畫面與多分頁驗證使用本機 WebKit，未在實體 iPad 上測試。
