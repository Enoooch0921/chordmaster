# 弱網路與離線啟動

已完整載入過的工作區會依帳號與歌曲庫 ID 儲存在 IndexedDB，包含歌曲、歌單、專案與已加入的共享內容。Web Storage 只保留最後使用的帳號／工作區指標；IndexedDB 無法使用時才嘗試容量較小的 Web Storage 備援。快取不保存登入憑證，也不使用原本個人區的工作區儲存位置，因此團隊歌曲不會寫入個人資料或覆蓋未同步草稿。

下次開啟時先讀取該工作區快取，還原其導覽位置，即可瀏覽歌譜、歌單與進入演出模式。登入確認或網路要求尚未完成時不顯示個人區，也不以全畫面載入遮住已有的快取。連線狀態以既有頂部工具列內的小圓點與「離線模式／Offline Mode」文字提示，不增加頂部區塊或高度；完成登入與版本確認後自動切為「Online」。更多說明保留在提示文字及既有同步狀態控制中。

快取啟動期間先提供瀏覽，確認登入、目前存取權與伺服器版本後才恢復編輯。背景讀取有 12 秒等待上限，失敗時保留畫面；重連、返回前景、手動重試，以及失敗後每 15 秒的重試都可重新確認。使用者在等待期間選擇的歌曲會保留。演出模式中的譜面不套用新版本，退出後才更新。伺服器已確認為空的工作區會清空過期快取內容，不會把刪除的歌曲復活。

登入還原遇到網路錯誤會與真正登出／登入失效區分。明確登出或驗證失敗會清除啟動指標，且尚未完成的快取寫入不能重新啟用該指標。其他帳號或明確指定的不同團隊不會誤用前一帳號／工作區的快取。

Service Worker 的導覽要求先回傳目前版本已安裝完成的 HTML，不再等待弱網路逾時。該 HTML 與已快取的版本資產保持一致，不用新版 HTML 覆寫舊 Worker 的快取。既有註冊更新流程仍會下載完整的新版本，等舊分頁關閉後啟用。

第一次使用或瀏覽器已清除儲存空間時，仍需要連線完整載入一次。尚未快取的歌曲、其他工作區與外部參考影片不保證離線可用。此功能不修改 NAS 結構或正式譜面資料。

驗證涵蓋 `src/App.workspaceStartup.test.tsx`、`src/lib/cloudWorkspaceCache.test.ts`、`src/lib/auth.offline.test.tsx`、`src/lib/serviceWorker.test.ts`。手機與平板尺寸使用實際 App 搭配合成資料及離線驗證狀態檢查；不使用正式帳號憑證或修改正式資料。

此功能隨 v0.11.4 發布。升級後先在線上完整開啟一次工作區，讓此裝置建立快取。已安裝的離線版本會等舊分頁關閉後再啟用更新；需要測試新版本時，先確認「關於」顯示 v0.11.4。
