# 0.12.5 — 鼓手播放、同步與小節差異

切換其他 App 後的 Click 恢復會重新連接原生音訊輸出，必要時重建播放 context，並保留已解碼音色。App 開啟後安靜預載三組音色，以 Ableton Live Classic 的一般拍及重音各自為基準平衡音量。聲音仍由原生循環持續輸出，畫面只讀取音訊時鐘，漏幀不會拖住 Click。

BPM 保留原生輸入與最多一位小數，行動裝置跟隨可視區域讓輸入數字保持可見，鍵盤收回後重新校正觸控定位。同帳號與演出模式持續更新歌單、Key 與譜面，保留目前選曲、翻頁及手動調整；播放中的速度與拍號保持到停止或換歌後再採用來源設定。

移除吉他手模式；樂譜標題下方 Key 右側僅顯示大於 0 的 Capo。修正三行小節的高度，並在歌單歌曲選單提供 1／2／3 行快捷設定。

版本提示依實際和弦、拍位及內容判斷，相同和弦的不同記法不再提示更新。歌詞、弱起拍、節奏及延續拍的變更分開說明；和弦差異以簡易小節並排顯示，新增／改動事件標色。

## 發布範圍與限制

沿用既有權限、來源版本與完整 JSON 併發檢查，不執行資料庫遷移或正式譜面覆寫。其他音樂 App 混音共存功能已移除，不包含在此版。

完整自動化測試、TypeScript 檢查及網頁／iPad 建置列入發布前驗證。桌面與手機寬度的小節預覽已在本機檢查；實體 iPhone／iPad 的背景、鎖屏、音訊中斷及系統鍵盤回歸尚未完成，不能由模擬測試推定為已通過。

發布前本機驗證：192 個測試檔案、2169 項測試通過，TypeScript 檢查、網頁正式建置及 iPad 建置通過。建置保留既有的大型 chunk 提醒，不影響成功結果。GitHub Pages 流程會再次執行完整測試、型別檢查及正式建置。
