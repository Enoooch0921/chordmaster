# ChordMaster 0.12.17 — 2026-11-07

這版整合 0.12.16 之後完成的動畫與操作修正、新版歌詞閱讀、原唱語言呈現、曲序及鼓手／節拍器改善，並整理 GitHub 專案首頁與文件入口。

## 歌詞閱讀

- 整份歌單使用相同字級，預設 24px，可在閱讀設定調整；手機、平板與電腦依可用空間安排欄位。
- 長句依原有空白換行並避免孤字，優先減少翻頁；閱讀設定與 A4 列印設定分開。
- 歌單、演出及分享頁使用新版閱讀器；分享內容更新時保留目前歌曲與歌詞模式。
- 支援段落與個別行的原唱語言，避免中文模式藏起應唱的英文。先前 PDF 核對後的〈Same God〉等資料可按主歌中文、副歌英文呈現，中文譯文保留作對照。來源核對範圍與尚待確認的歌曲見[原唱語言稽核](topchurchworship-sung-language-audit-2026-11-06.md)。

## 動畫、觸控與操作

- 開關左側面板時維持譜面位置，手機「歌曲／歌單」切換採一致回饋。
- 歌單卡片的留白也能點按選曲；Key、BPM 與更多操作維持獨立。
- 演出翻頁改為觸控位置的局部回饋，避免整張譜面晃動。
- 彈出選單與設定面板可在動畫途中反向、快速重開或由鍵盤接手；減少動態時取消位移。
- 修正演出焦點被搶回、左滑動作自動收起、取消觸控仍輸入及通知操作中消失等問題。
- Key／Capo／BPM 面板依可視範圍定位，過長內容可捲動；長檔名通知允許換行。

## 歌曲庫、曲序與鼓手

- 歌曲庫每頁建立最多 60 列，搜尋與總數仍涵蓋全部資料；跨搜尋與跨頁保留同一份批次選取。
- BPM 不合法文字不再被截短後當作有效數字保存，保留輸入並顯示錯誤。
- 曲序採緊湊段落標籤，補上直接跟隨指標的拖曳預覽；邊緣捲動依經過時間計算，減少不同螢幕更新率的速度差異。
- 一般歌單保留版本，鼓手歌名去除可辨識的版本／語言後綴，原始資料及真正副標題保留。
- 參考音源 TAP 與鼓手採一致的立即按住回饋，不以縮放動畫干擾測速。
- 節拍器停止時立即靜音，保留已準備音訊路徑 1.5 秒，縮短連續停止／重開時的準備流程；重開由第一拍開始。

## 整合與發佈範圍

本次已核對歌詞設計、曲序樣式及節拍器快速切換等相關對話，整合主工作區內已完成的程式、測試與文件。先前已整合的舊工作樹不再覆蓋較新的主工作區。僅供比較的配色稿、工具快取與本機瀏覽器截圖保留在本機。

GitHub 首頁改為精簡功能介紹、線上入口、開發指令及[文件索引](README.md)；儲存庫 About 補上說明、網站連結與主題。本版也加入可獨立查閱的 GitHub Release。

本次部署只更新 GitHub Pages 前端，沒有新增 NAS migration、重寫歌曲資料或發佈原生 iPad App。先前已完成的 PDF 歌詞資料核對不重複寫入；歷史 Supabase Cloud 不參與此次發佈。
