# ChordMaster 0.12.26 — 2026-11-07

這次針對全螢幕樂譜仍會在換歌時停頓的問題，修正預載譜面共用當前歌曲版面尺寸的情況。之前即使下一首已經載入，從雙頁歌曲換到單頁歌曲，或反向切換，仍會改到所有已預載歌曲的欄數、寬度與縮放，並重新量測頁面位置。

現在前後相鄰曲目依自己的頁數、畫面方向與可用空間預排。換歌沿用各首歌曲的尺寸與頁面位置，保留原來的筆記顯示層；返回上一首仍開啟最後一頁。旋轉畫面或收到歌曲更新時，仍會依新的版面重新量測。

本機型別檢查、239 個測試檔的 2,758 項測試及 iPad 建置通過。新增混合單頁／多頁歌曲、橫直向切換與來源分頁更新的回歸測試。WebKit 的 iPad 模擬視窗也核對譜面置中、邊界、實際書寫、跨歌保留筆跡及返回上一首末頁。

在 1194×834 的本機 WebKit 視窗，以 64／16／96／24 小節及個人筆跡組成的合成歌單交替比較兩版，各取 12 次跨歌。輸入至下一個動畫影格回呼的中位數由 101.5ms 降至 45ms，範圍由 77–159ms 降至 23–87ms；切換期間 `offsetTop` 讀取由每次 6–12 次降至 0 次，12 次都保留鄰曲欄數、寬度與筆跡節點。這是瀏覽器排程指標，並非實際螢幕完成繪製時間，也不是 iPad 實機數據。

這次修正可消除已確認的切換重排；本機模擬不能代表實際 iPad 的 GPU 與記憶體狀況，因此尚未宣稱所有裝置的卡頓已完全消除。

## 在 iPad 更新

先退出演出模式，點「立即更新」並確認版本為 **v0.12.26**。用橫向全螢幕樂譜測試一首只有一頁、另一首需要兩頁以上的歌曲，前後以點按與滑動切換，再確認個人筆記與上一首末頁位置。
