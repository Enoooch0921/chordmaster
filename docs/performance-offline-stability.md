# 演出模式與離線翻譜（0.9.15）

適用重點是 iPad 加入主畫面的版本。演出前在線上開啟這次完整歌單及要用的譜面，確認曲序、調性和內容；演出中保持頁面開啟。已載入的歌譜與翻頁使用裝置內資料，不依賴每次翻頁連線。

## 本次修正

- 演出期間，個人／團隊歌曲庫、歌單與加入的共享歌單暫緩套用背景更新。重新連線也不回填尚待同步的資料；退出演出再補讀。已開始的讀取亦重新檢查演出狀態，防止舊回應覆蓋台上內容。
- iPad PWA 的 DOM 焦點可能仍指向鍵盤接收框，但系統已停止把硬體鍵盤送過去。因此演出中每 1.5 秒重新呼叫 `focus({preventScroll:true})`，不再因 `activeElement` 相同而略過。回到前景、pageshow 與視窗 focus 時立即恢復；隱藏、對話框開啟及退出演出後停止搶焦點。
- 一次按下／放開只翻一次；長按自動重複不連翻，支援只送 keyup 或只送 keydown 的裝置。Space、Enter、方向鍵與 PageUp／PageDown 保留。
- 一次滑動後的合成 click 不再翻第二次，不以短時間窗判斷，避免慢裝置延遲處理時失效；下一個觸控或實際滑鼠動作恢復正常。
- 未改變的歌曲資料維持參照，譜面使用 memo；翻頁／狀態心跳不重建整份相同譜面。
- Service Worker 不再於 install 強制 skipWaiting。新版等目前開啟的頁面全部結束後才啟用，避免台上舊頁面的離線檔案被新快取清除。不要求台上使用者刷新。新版的所有程式分包與核心譜面字型必須下載成功才安裝，下載中斷不會把不完整的新版本取代可用舊版。

## 驗證與限制

本機 1,033 項測試通過，包含實際 App 的演出離線／重連、鍵盤與觸控測試，以及 30 分鐘模擬閒置的焦點恢復測試。測試 worker 限制為 2，以控制多頁 App 整合測試的記憶體；這不影響產品執行。

正式建置候選以 1024×1366 直向、1366×1024 橫向的桌面瀏覽器測試，使用 standalone／觸控能力 fixture，確認單／雙頁不超出螢幕。停止本機伺服器後，鍵盤及觸控可跨歌曲翻譜；已快取的本機歌單也可離線重載。另安裝第二個 worker 候選，確認它等待更新、既有演出歌曲及頁碼不變。證據在 `tmp/release-performance-20261026/`。

這些不是實體 iPad Safari 或實際藍牙翻譜器的長時間連線實測。對使用者回報「其他 App 正常、ChordMaster 閒置後只剩手動翻頁」已修復焦點恢復的程式缺口，但仍應以該 iPad／翻譜器實測確認。共享歌單與團隊庫冷啟動的完整離線下載不在本次新增範圍；勿假設未載入的歌譜或媒體能離線取得。外部影音仍需網路。
