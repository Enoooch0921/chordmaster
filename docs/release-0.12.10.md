# 0.12.10 — 一鍵更新與開屏版本號

新版完整下載後，顯示「立即更新／稍後」。按更新會先儲存目前內容，再重新載入此分頁；儲存失敗時保留頁面與錯誤提示。其他分頁可繼續使用，演出及鼓手模式不顯示更新提示，也不會自動重載。

HTML 初始畫面及 React 開屏動畫都顯示建置版本號。版本取自 package.json，發布時自動更新。

舊版尚未包含更新提示，首次取得 0.12.10 仍需完成一次原有的關閉分頁／重開流程，後續版本可直接按提示更新。
