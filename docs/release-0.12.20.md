# ChordMaster 0.12.20 — 2026-11-07

手機歌詞閱讀將歌名與工具合併為一列，收起調性、Capo 等樂譜工具，增加歌詞區高度。未儲存字級的手機預設使用 22px，既有字級偏好仍保留；可在閱讀設定以 2px 調整，最低 20px。分頁優先保持完整段落，只有能減少頁數時才使用剩餘空間拆段。

在 390×844 的本機 App 測試中，〈點燃〉的歌詞區由 480px 增至 595px，頁數由 3 頁減為 2 頁；第一頁能顯示兩段主歌與完整副歌。

手機、平板的一般歌詞閱讀也能左右滑動翻頁，或點左半邊往前、右半邊往後。最後一頁繼續往後會進入下一首；往前一首會開啟最後一頁。直向捲動、雙指與選字保留原有用途，滑動放手後只翻一次。WebKit 下拉選單的實際點按高度補齊為 44px。

## 手機和平板試用

1. 開啟 ChordMaster，若在演出模式，先退出；看到新版提示後點「立即更新」。確認開屏或關於頁顯示 **v0.12.20**。
2. 打開歌詞模式，試閱〈點燃〉；可在閱讀設定檢查字級。若原先存過字級，仍沿用該數值，可手動調為 22px 比較。
3. 在歌詞內容區點左右半邊、向左右滑動，並試著翻過最後一頁及返回上一首。閱讀設定、列印與選曲選單仍可正常操作。

本機已驗證 Chromium／WebKit 的手機、平板、橫直向、淺深色及來源行完整性；觸控驗證使用模擬觸控輸入與合成事件，實體手機和平板由本次試用確認。詳細證據與限制見[手機歌詞閱讀驗證](mobile-lyrics-reading-2026-11-07.md)。本版僅發布網頁，沒有資料庫遷移或正式歌曲寫入。
