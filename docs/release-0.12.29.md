# ChordMaster 0.12.29 — 2026-11-07

修正全螢幕樂譜連續往後翻時，第一次進入下一首會停頓的問題。即使下一首已經在記憶體裡，顯示該曲的個人筆記按鈕仍可能使 WebKit 大範圍重算樣式。現在這組工具直接顯示在所屬的演出畫面內。

預載的譜面圖層加了一個透明的邊緣，讓 WebKit 可以在空檔先畫好它。歌譜本身保持在畫面外，翻頁時直接切換。

## 驗證

在本機 WebKit 的 iPad 橫向視窗，以七首共 484 個來源小節的歌單和合成筆跡，連續前進到最後一首，再返回第一首。兩版在這次對照開始時都已預備七首。v0.12.28 的六次首次跨歌各有一次 285–290 毫秒的樣式重算，修正後每次最長的樣式重算均低於 1 毫秒。另在進入演出約 100 毫秒後開始連翻，六次跨歌都沿用已建立的目標譜面，背景仍需要時間完成其他曲目。

另外在 iPadOS 27.2 的 Safari 模擬器以直向逐頁前進 14 次、返回 14 次，核對了完整曲序與頁碼。

以上效能數字來自瀏覽器時間軸，衡量的是樣式重算。實體 iPad 從觸碰到畫面顯示的時間仍需在裝置上確認。
