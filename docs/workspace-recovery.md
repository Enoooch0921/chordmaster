# 儲存、離線與畫面復原

## 個人曲庫

離線待同步內容依 `userId`、`libraryId` 分開存放。`deletions` 只記錄相對於最後成功載入／儲存版本消失的 ID，以及該項目最後看過的 `updatedAt`。

重新連線合併時，本機沒看過的遠端項目必須保留。如果遠端項目已比刪除記錄中的版本更新，也保留遠端版本。`savedAt` 不能作為整個曲庫的刪除證據。

舊版未標示帳號的待同步資料不會自動套用到目前登入帳號。介面提供下載及確認帳號後恢復；舊資料沒有逐項刪除證據，因此恢復以保留資料為優先。

## 團隊草稿

`teamDrafts.ts` 保存每個帳號、團隊自己的工作內容及編輯前基準。草稿在編輯後和頁面隱藏時寫入；雲端儲存成功只清除內容相符的草稿，不能清除儲存期間新增的修改。

重新進入團隊後，使用者可以下載、捨棄或恢復草稿。恢復只套用相對於原基準的修改，保留雲端新增及未編輯項目的更新。雙方改到同一項目時，介面會先要求確認。恢復仍經過既有雲端權限檢查，不會離線繞過權限。

這是草稿救援機制，不是多人即時協作或伺服器端版本鎖。同一筆資料的線上並行寫入仍需要另外設計伺服器版本檢查。

## 畫面與 PDF

路由和編輯器由 `RecoveryBoundary` 提供錯誤提示、重試及 JSON 備份下載。備份保留最近一次提交到畫面的歌曲、歌單、專案及預覽編輯狀態。原生 App 使用系統檔案分享，網頁使用檔案分享或下載。

PDF 實作位於 `pdfExport.ts`，由匯出按鈕按需載入。分享資料只能包含 `files`，不加入 `title`、`text` 或 `url`。取消分享不應再下載另一份檔案。

## 發布與離線驗證

- 發布前必須通過 `npm run lint`、`npm run test:run`、`npm run build`。
- Pull request 額外執行 `npm run build:ipad`，不會同步或部署到實體裝置。
- 建置會把所有 JS、CSS 檔案寫進 service worker 快取清單，包括延遲載入的編輯器與 PDF 模組；更新只清除 ChordMaster 自己的舊快取。
- 真機驗收：iPhone／iPad 匯出只收到 PDF；團隊離線修改後關閉重開可恢復草稿；兩台裝置分別新增內容後重連不誤刪；分享連結可直接開啟。
