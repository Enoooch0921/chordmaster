# 0.12.3 — 緊急修復 Click 跨小節停頓

0.12.2 使用 HTMLAudioElement 循環一小節音訊，瀏覽器 loop／seek 交界不保證無縫，可能讓第 4 拍接回第 1 拍時出現空檔。0.12.3 將可聽見的 Click 改為原生 AudioBufferSourceNode 循環，不再重播媒體檔案。

音訊時鐘控制聲音與拍點。調速保留當下拍內位置，新來源的開始與舊來源的停止排在同一音訊時間；換音色仍在新取樣準備完成後接替。獨立的靜音媒體工作階段輔助不承接 Click 聲音。

## 驗證

- 64 項相關測試通過，包含 PCM 小節尾首間隔、原生循環設定、調速相位、換音色失敗保留及歌單入口。
- 本機瀏覽器以實際 OfflineAudioContext 渲染 72、120、128、137、180 BPM 各八小節，所有 4→1 邊界誤差小於 1 個 48 kHz 取樣（約 0.021ms）。這是原生音訊引擎的離線渲染驗證，不等同實體裝置錄音。
- TypeScript 檢查與正式建置；發布 commit 由 GitHub Pages 執行完整測試與部署。

iPhone／iPad 主畫面版本的背景、鎖屏與實際輸出仍待實機驗證；不將靜音媒體輔助視為所有 iOS 版本皆可持續背景播放的保證。
