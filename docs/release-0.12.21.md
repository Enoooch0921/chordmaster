## 在 iPad 試用

1. 開啟 ChordMaster，先退出演出模式，再點「立即更新」，確認版本為 **v0.12.21**。
2. 使用平常會卡的歌單，到一首歌的最後一頁，點右半邊進入下一首，再向右滑回上一首。
3. 轉成橫向試雙頁，退出演出後確認工作區仍選中剛才的歌曲。
