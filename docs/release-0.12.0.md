# 0.12.0 — 鼓手模式與演出控制

本次網頁版從 0.11.20 升至 0.12.0，保留既有編輯、同步、權限與歌曲複製功能。從歌單下方開啟鼓手模式，使用本次歌單版本與速度；點歌即播放 Click，速度、重音、拍號與細分的演出調整不回寫共用譜面。

- 三種 Click 音色：MultiTracks、Drive、Ableton Live Classic。使用 Web Audio 音訊時鐘排程，支援逐拍重音、四分／八分／三連音／十六分等細分。
- BPM 可直接輸入、加減、TAP 測速或還原。TAP 在按下瞬間取樣，立即給予明確按壓回饋。
- 手機橫向把拍點放在上方、速度放在中間，底部保留播放、TAP、上下首；右側歌曲卡片顯示順序、拍號、速度與歌名，依切歌方向露出相鄰歌曲。
- 大螢幕演出模式集中左側歌單與控制，右側完整顯示 A4，點按歌譜翻頁。直向演出模式隱藏歌譜。一般／演出切換可正確離開全螢幕。
- 鍵盤與支援 Web MIDI 的瀏覽器可學習控制對應、儲存個人配置；可設定播放、TAP、加減速、上下首與樂譜翻頁，MIDI 另支援相對值速度旋鈕。瀏覽器未提供 MIDI 時顯示支援限制。
- 支援 Audio Session API 的瀏覽器會請求媒體播放類型，改善 iPhone／iPad 靜音模式下的 Click 播放。尚未完成實機靜音開關及硬體控制器驗證；不支援此 API 的版本保留原有 Web Audio 行為。
- 吉他手模式移至更多選單，保留既有功能。

本次僅發布網頁版，不發布 iOS 原生 App，不執行資料庫 migration 或歌曲資料寫入。離開頁面、鎖屏或音訊中斷仍會停止 Click，需要回到頁面手動播放。
