# ChordMaster 0.12.18 — 2026-11-07

修復 0.12.17 發佈驗證中發現的兩個既有樂譜字型解碼警告，並依使用者回饋重新設計全螢幕左右滑動的視覺形式。

## 字型修復

- `JianpuASCII.ttf` 曾被當成 UTF-8 文字處理，產生 5,474 個替代字元，破壞字型表位置。已從原作者找回完全對應的 2.3 原始二進位檔：對原檔進行同樣的錯誤轉換，能逐位元組重現舊損壞檔案。沒有升級到不同字形的新版。
- `BachSlurs.ttf` 的字型目錄、cmap 搜尋欄位及 maxZones 格式不合法，已重建。字形輪廓、字元映射、字形順序、寬度／間距與 hint 程式比對一致。
- 同步修復來源副本與簡譜字型授權文字；[字型來源、校驗值與重建方式](../public/fonts/README.md)可供後續維護。
- 瀏覽器載入、PDF 內嵌、Service Worker 預載均使用一致的版本網址，避開舊離線快取中的損壞檔案。

目前主要簡譜以系統字體搭配圖形排版，連線也有圖形繪製，因此這些警告不代表歌曲資料或所有現有符號都已損壞；原先字型預載及匯出內嵌仍會嘗試載入它們。

## 全螢幕翻頁

- 移除跟著手指移動的黑色圓形箭頭，改成翻頁方向一側、靠近手勢起始高度的短暫淡光。
- 淡光為 4 × 80px，停在畫面邊緣；沒有平移、彈跳、放大或旋轉。譜面仍保持固定，達到翻頁條件才立即換頁。
- 先確認水平滑動意圖才顯示方向，避免剛碰畫面就猜錯方向、垂直移動也閃出提示。
- 快速反向只切換提示所在邊緣；取消、多指及滑動後的相容點擊仍受保護，不會重複翻頁。
- 鍵盤操作立即生效，不播放觸控動畫；減少動態設定僅保留 80ms 淡出。原有固定翻頁按鈕與鍵盤功能保留。

## 驗證

- 完整 Vitest：238 個測試檔、2,745 項測試通過。
- TypeScript 型別檢查、正式網頁 build 與 iPad 資產 build 通過；保留既有大型 chunk 提示。

- Chromium／WebKit 的三個應用字型都能以網址及 PDF 使用的 data URL 載入為 `loaded`，未再出現兩個字型的解碼警告。
- 使用實際 PDF 匯出流程建立合成符號驗證檔，下載成功；轉成圖片後確認簡譜、高低音點、底線、節奏音符及連音線正常。
- Chromium／WebKit 的 390／834／1440px 尺寸檢查：滑動前不閃提示、譜面位置固定、淡光不追手、反向／取消正確、翻頁一次、相容點擊不重複翻頁；鍵盤無殘留提示，減少動態淡出為 80ms。

瀏覽器手勢使用合成觸控事件，不等同實體手機或平板的手感與更新率量測。本版沒有讀寫正式歌曲或變更 NAS 資料庫。
