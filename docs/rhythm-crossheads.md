# 節奏叉形音頭

既有節奏資料不需遷移。讀寫新記號需使用支援叉形音頭的客戶端；舊版客戶端無法顯示新記號。

`c` 表示叉形音頭，`cu` 表示原譜中位置較高的叉形音頭。例如 `qc` 是四分叉形音頭、`ecu` 是位置較高的八分叉形音頭。位置只用於忠實呈現原圖，不指定鼓件、聲部或音高。

- 支援四分、八分、十六分音符，以及既有四分／八分三連音、附點、重音和連結。
- `qx`、`ex` 等舊有 `x` 後綴仍為隱藏空拍。叉形音頭不是休止，也不是佔拍斜線。
- 暫不支援全音符或二分音符叉形，以免兩種時值畫成相同符號。編輯時會要求先取消叉形，再改成這兩種時值。
- 預覽編輯器的 `×` 按鈕依次切換實心、一般叉形、上方叉形、實心。原有與預覽編輯器都會在其他節奏編輯中保留音頭資訊。
- 含叉形的小節採共用向量音頭、符桿和連桿；沒有叉形的小節沿用 Bach 字型。一般與 compact 模式都支援。
