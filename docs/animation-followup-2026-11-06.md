# 側欄抖動與操作回饋改善

本輪於 2026-11-06 開始、11-07 完成。使用者要求繼續改善有交互意義的動畫，並補充平板／電腦左側面板展開與收起時，整張歌譜會抖動。保留先前固定譜面翻頁、觸點提示、手機歌曲／歌單分類動畫與擴大點擊範圍的修改。

## 已修正

| Before | After | Why |
| --- | --- | --- |
| 桌面側欄先改占位寬度，預覽要等 ResizeObserver 的下一個 RAF 才重新置中／縮放 | 已知的側欄寬度、編輯器布局及工具列布局改變，在 layout effect 同步測量，首個畫面直接使用正確位置 | 消除新容器配舊譜面位置的中間畫面，不為整張譜加位移動畫。`src/App.tsx` 的預覽測量 effect |
| 滑鼠暫時展開導航也擠壓主內容 | hover 僅覆蓋；固定側欄才占用寬度，調寬把手也只在固定時出現 | 暫看導航不應重排正在讀的譜面。`sidebarReservesSpace` |
| 手機關閉導航會把同一首歌重新定位到開頭 | 覆蓋時僅暫停捲動追蹤，保持導航生命週期；同曲關閉保留位置，換歌仍正常定位 | 開關面板不是重新進入歌曲。`useSetlistPreviewNavigation` 的 App 呼叫處 |
| 歌單選取背景漸變 150ms，文字顏色立刻改變 | 選取背景與文字同步、立即切換；拖曳鄰列原有動畫保留 | 高頻切歌不應短暫出現淡字配淺底。`ProjectManagementPanel.css` |
| 歌曲庫全部／最近使用／收藏、歌詞閱讀／列印硬切各自底色 | 重用 `MeasuredSlidingSelection`，選取底片 160ms，文字及資料立即更新 | 同層選項給狀態位置提示；依實際按鈕寬度移動，快速反向從當前位置接續。鍵盤／減少動態時立即切換 |
| 篩選、已選清單、歌詞設定直接出現／消失；箭頭沒有一致回饋 | 重用 `AnimatedDisclosure` 的 125ms opacity，關閉立即 inert／aria-hidden；箭頭 160ms，補齊 Tailwind 個別 `rotate` 屬性的 transition | 偶爾展開附加工具時提供狀態提示，不逐幀改 height 或移動閱讀內容；鍵盤立即、減少動態取消旋轉 |
| 演出工具列顯示及隱藏都需 500ms，鍵盤／踏板也播放 | 顯示 125ms、隱藏 160ms；鍵盤／踏板 0ms；減少動態使用 125ms opacity | 提示要及時、不能妨礙高頻翻頁；維持 DOM dataset 更新，不增加 App 逐幀 render |
| 加入主畫面引導關閉直接卸載，既有退出動畫沒有機會執行 | 補上 AnimatePresence 邊界，沿用現有 native dialog 的 200ms 手機／160ms 桌面退出 | 開關路徑一致，確認「已加入」的偏好立即更新，退出期間停用操作 |
| PDF 進度動畫改變 width，忙碌圖示忽略減少動態 | 固定寬度、左側原點 scaleX，200ms 共用 ease-out；減少動態立即更新且停止轉圈，補 progressbar 語意 | 避免匯出忙碌時逐幀重新排版，仍保留文字進度 |

共用曲線沿用 `UI_EASE_OUT`／`--ease-ui-out`（0.23, 1, 0.32, 1）；側欄／手機 dialog 沿用 drawer 曲線（0.32, 0.72, 0, 1）。沒有加入新動畫套件。

主要審查定位：`src/App.tsx:2264`（側欄占位）、`src/App.tsx:4577`（首幀測量）、`src/App.tsx:10782`（手機閱讀位置）、`src/App.tsx:15558`（匯出進度）、`src/index.css:23`（演出工具列）、`src/index.css:666`（箭頭回饋）。
