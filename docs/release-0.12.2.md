# 0.12.2 — Click 播放穩定性與背景播放

Click 改以完整小節 PCM WAV 交給 HTML 媒體播放器循環播放，背景音訊不再依靠頁面計時器。Web Audio 僅解碼取樣，不承接媒體輸出；節拍畫面跟隨媒體時間。切換 App／分頁時不主動停止，回來後同步拍點；系統若已暫停播放則嘗試恢復。手動停止仍保持停止，並支援系統媒體的播放、暫停與停止操作。

新使用者預設 Ableton Live Classic，保留既有儲存音色。換音色先載入並準備新聲音，期間舊聲音繼續；顯示準備進度，自動重試一次，失敗時保留原音色並還原選項。載入與啟動設有期限，避免持續卡在等待。

歌曲觸控放開時直接選取，保留滑動、取消及重複 click 的保護。一般與演出模式的平板／寬螢幕排列統一為拍點在上、速度在中、底部播放／TAP／上一首／下一首；縮放跨過 1440px 也不切回舊排列，控制區最大寬 600px。

## 驗證與限制

發布前執行完整測試、TypeScript 檢查與正式建置，GitHub Pages 工作流程另對發布 commit 重做檢查。測試涵蓋 PCM WAV 小節長度、重音／細分／靜音、播放時鐘、音色失敗回復、觸控選曲、背景返回及手動停止。

本機瀏覽器已驗證三種音色切換與媒體循環。內建瀏覽器切換分頁時未回報 hidden，因此沒有將該環境列為真正背景實測。iPhone／iPad「加入主畫面」後的背景、鎖屏、長時間連續輸出與循環交界仍待實機驗證；此版不宣稱所有裝置均已通過。舊 Web Audio 的 30 分鐘排程模擬不等同新版實機背景測試。
